# Pact skills

Claude Code loads these automatically when a session starts in the repo root. Call one by name in a prompt, for example "Using the pact-frontend skill, build ...".

| Skill | Use it for |
| --- | --- |
| pact-spec-guardian | The check before any task: invariants, scope, gates, demo flow, copy rules |
| pact-build-workflow | Task lists, prompt templates, review checklist, commits, fallbacks, handover |
| pact-contracts | Data types, endpoints, engine algorithms, demo figures, Claude usage |
| pact-frontend | Tokens, layout patterns, the 10 screens, chart spec, emoji policy, accessibility |
